# Implementation Plan Gate

Use this gate after implementation plan creation and before implementation.

## Purpose

Make sure the planning step is actually complete and that the user explicitly confirmed the plan is good enough to continue.

## Checklist

- The implementation plan was completed in full.
- The expected code changes, files, tests, QA, and validation approach were planned concretely.
- Assumptions and questions were listed alongside recommendations or suggested answers.
- The user reviewed the plan and assumptions/questions.
- The user explicitly confirmed the plan is good, or explicitly said to proceed.
- A Jira ticket was created or updated with the implementation plan.

## Rule

Do not continue to implementation until the user explicitly confirms that the planning stage is complete or explicitly says to proceed.
